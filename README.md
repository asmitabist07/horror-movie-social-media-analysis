# Horror Movie Social Media Analysis

## Project Overview

This project investigates horror movie data using social web analytics techniques for the COMP3020 group assessment.

## Research Questions

1. What patterns can be identified in the horror movie dataset?
2. Which horror movies have the highest values for the popularity measure available in the dataset?
3. What relationships between horror movies can be identified through network analysis, if supported by the available data?

## Dataset

The project uses a dataset containing horror movie information. The dataset is included in this repository.

The specific variables and number of records are determined by the dataset provided.

## Methods

The R script is used to analyse the dataset and generate visualisations. The analysis includes the methods implemented in the script, such as data preparation, descriptive analysis, bar charts, and network analysis where applicable.

## Files

* `horror_analysis.R` – R script containing the analysis.
* `horror_data.csv` – Dataset used in the analysis.

## Tools

* R
* RStudio
* GitHub

## How to Run

1. Download the R script and dataset.
2. Open the script in RStudio.
3. Set the working directory to the folder containing both files.
4. Install any required packages.
5. Run the script to reproduce the analysis.
